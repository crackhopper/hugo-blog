# The Plenoptic Function
$P(\theta,\phi,\lambda,t,V_x,V_y, V_z)$

![[RT-06-光场-LightField-the-plenoptic-function-01.png]]

Only need plenopic surface 。只需要在物体包围盒包面记录光的强度即可。因此相当于把任意的 $V_x, V_y, V_z$ 转变为，物体包围盒表面+表面上任意方向。表面用两个参数即可，表面上的方向同样也是两个参数，所以一共4个参数。这个4个参数的函数即为广场。（因此是全光函数固定的lambda和t；并将 $V_x,V_y,V_z$ 降维到表面；即将全光函数降低到仅需要4个自由度）

# 记录光场

![[RT-06-光场-LightField-记录光场-01.png]]

- (a) : 我需要在 u,v 平面的每一个位置上，拍摄整个 s, t 平面。（设备：摄像机阵列）
	- 即：固定 u,v, 得到 s,t 的函数是什么？显然是一个相机画面。
- (b) : 对s,t 平面的每个点，包含着方向信息，全部记录在 u,v, 平面
	- 即：固定 s,t ,得到 u,v, 的函数是什么？是针对一个具体发光点，记录的irradiance。

设备：分光透镜。将不同方向进入的光线，分到不同的存储位置上。即（一次可以捕获多个方向的光照）。如下图：
- ![[RT-06-光场-LightField-记录光场-02.png|384x255]]
- 光场相机优点：先拍照后聚焦。（因为光场捕获了，以为着所有的光线都被记录了）
- 理解：其实是不同颜色的光，相当于不同的相机。（摄像机阵列则是：把红绿蓝，分别分离出来，单独记录。而光场相机则是：针对每个u,v上的点，记录整体的 irradiance。）
