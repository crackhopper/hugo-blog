# 光子映射(Photon Mapping)
擅长解决caustics的问题。

![[RT-05-高级话题简述-光子映射photon-mapping-01.png]]

光线聚焦形成的现象。（多个光路都集中到某个点上的现象）


步骤：
1. 光子tracing：从光源出发：光子打到diffuse的物体上停下来。
2. 光子collection：从相机出发：假的光子打到diffuse的物体上停下来。
3. 局部密度估计(local density esitmation):
	1. 对任意的着色点，找附近最近的K个光子。
	2. 计算这些光子所占据的面积。和光子的数量。

光子映射：有偏估计，因为：
- dN/dA != \Delta N / \Delta A

但最终一致。当光子数量足够多，结果就会对。（Bias的视觉效果，blurry）

Bias 和 Variance 是trade-off

## 头发 (Hair Appearance)
### Kajiya-Kay Model
考虑是圆柱：一部分按照圆锥反射（高光），一部分则是diffuse

![[RT-05-高级话题简述-kajiya-kay-model-01.png|479]]
### Marschner Model
![[RT-05-高级话题简述-marschner-model-01.png|602]]

修复Kajiya-Kay模型
- R: 反射
- T: 进入头发
- TT：整个穿透头发（两次折射）。
- TRT：进入光线，反射，然后再被折射出来。

更具体的考虑：把头发当作玻璃圆柱，且头发内部有色素。
![[RT-05-高级话题简述-marschner-model-02.png|505]]
这样主要考虑3中光线和圆柱的作用：
- R:直接反射
- TT:穿透头发（被头发色素影响）
- TRT:穿入、反射、再穿出


当和整个头发一起计算，就能得到很好的效果。（因为头发弹射光线会和另外的头发交互，导致计算量很大）

## Detailed Appearance
过于完美，导致不真实。

具体做法：
- $D(h)$ : 用更复杂的模型去贴和它。利用一些细节贴图。
	- 不同的法线贴图，可以计算得到不一样的 p-NDF
	- 同样可以反向，来预计算出一些法线贴图。

### Wave Optics
考虑光的波动性的渲染。需要利用波动光学的知识。

发生现象的时机：某个单色光照射表面，得到了其他颜色光。说明微观上有波动光学效应。
