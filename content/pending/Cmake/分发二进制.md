对于我们构建待分发的一个二进制来说。

# 1. install
cmake的install命令，提供了安装时的选项。

a.拷贝对应的文件，比如
```cmake
install(DIRECTORY include/  
	DESTINATION include  
)
```

b. 注册要导出的target
```cmake
install(TARGETS LX_Graphics
    EXPORT LXGraphicsTargets
    ARCHIVE DESTINATION lib
    LIBRARY DESTINATION lib
    RUNTIME DESTINATION bin
    INCLUDES DESTINATION include
)
```

c. 生成target文件（会将target本身属性上的设置，或者install Target上的属性设置；把这些变量具体记录下来）
```
install(EXPORT LXGraphicsTargets
    FILE LXGraphicsTargets.cmake
    NAMESPACE LX::
    DESTINATION lib/cmake/LXGraphics
)
```

# 2. configure_package_config_file
生成config文件的流程

```cmake
include(CMakePackageConfigHelpers)

configure_package_config_file(
    cmake/LXGraphicsConfig.cmake.in
    ${CMAKE_CURRENT_BINARY_DIR}/LXGraphicsConfig.cmake
    INSTALL_DESTINATION lib/cmake/LXGraphics
)

install(FILES
    ${CMAKE_CURRENT_BINARY_DIR}/LXGraphicsConfig.cmake
    DESTINATION lib/cmake/LXGraphics
)
```

## 2.1 XXConfig.cmake.in
这个文件是分发者提供的，内部引用install步骤生成的target.cmake。
```
@PACKAGE_INIT@

include("${CMAKE_CURRENT_LIST_DIR}/LXGraphicsTargets.cmake")
```

# 总结
整个cmake包配置模块：
```
$<BUILD_INTERFACE>
$<INSTALL_INTERFACE>
install(TARGETS ...)
install(EXPORT ...)
configure_package_config_file()
```

# 整个流程的真实时间线
## 构建阶段
1. add_library 创建 target
2. target_include_directories 设置 usage requirement
3. install(TARGETS ... EXPORT ...)
4. install(EXPORT ...) 注册 export 规则
5. configure_package_config_file 生成 Config.cmake

## 安装阶段（执行 make install）
1. 复制 lib/include
2. 生成 LXGraphicsTargets.cmake
3. 安装 LXGraphicsConfig.cmake

## 使用阶段（find_package）
1. 加载 LXGraphicsConfig.cmake
2. include LXGraphicsTargets.cmake
3. 创建 IMPORTED target
4. 设置 INTERFACE_INCLUDE_DIRECTORIES
5. 设置 INTERFACE_LINK_LIBRARIES
